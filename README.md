# 🚗 汽车注塑件成本模型 · 专业增强版

一款专为汽车行业成本工程师、模具工程师和采购人员设计的**在线成本估算工具**。帮助您在几秒钟内，基于详细参数（模具结构、材料、表面处理、物流模式），快速、透明地计算出注塑件的生产成本。

## ✨ 核心功能

- **⚖️ 智能重量计算**：支持自动计算（投影面积×壁厚）或手动输入净重，并可设置废品率。
- **💰 模具费精确核算**：按模架、型腔、标准件、辅助系统、抽芯、热流道、设计试模费**7大项**逐一构成，完全透明，告别黑盒估算。
- **💳 灵活的模具支付**：支持“供应商全承担”、“主机厂全支付”、“双方按比例分摊”三种模式，贴合实际商务场景。
- **🎨 可维护的表面处理库**：支持喷涂、电镀、包覆等工艺，按面积计价，并可自定义单价、厚度系数。
- **🚚 科学的物流计费**：支持按实际重量、按体积重量、或两者取最大值三种计费模式，解决大型薄壁件运费偏差问题。
- **📊 实时成本构成图**：以饼图直观展示各项成本占比。
- **💾 数据本地自动保存**：所有自定义的材料价格、表面处理工艺等数据，都会自动保存在您的浏览器中，关闭或刷新页面不会丢失。

1.  **填写参数**：在左侧面板输入零件尺寸、材料、模具结构、表面工艺和物流距离等。
2.  **点击测算**：点击「开始测算」按钮，右侧立即生成详细的成本构成和报价。
